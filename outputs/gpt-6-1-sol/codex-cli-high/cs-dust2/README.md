# DUST II · Protocol

可在浏览器直接游玩的本地 5v5 第一人称射击原型。React 18 + TypeScript + three.js，运行时依赖仅有 `react`、`react-dom`、`three`。地图、角色、武器均由代码生成；音效由 Web Audio 合成；场景标识使用运行时 Canvas 绘字，无外部模型、图片、贴图、字体或音频文件。

## 启动

推荐 Node.js 22.18+。

```sh
npm install
npm run dev
```

访问终端显示的地址（默认 http://localhost:5173），选择阵营、回合类型与武器后点击 **进入战场**。首次点击会激活音频并锁定鼠标。`Esc` 暂停并释放鼠标，点击 **继续行动** 返回。需要桌面浏览器与 WebGL；键鼠操作。

```sh
npm run build   # TypeScript 检查 + 生产构建
npm run preview
```

生产输出位于 `dist/`。

## 操作

| 按键            | 功能                                  |
| --------------- | ------------------------------------- |
| WASD / 鼠标     | 移动 / 瞄准                           |
| 左键            | 射击（步枪按住连射，手枪与 AWP 单击） |
| 右键            | AWP 开镜 / 关镜                       |
| 空格 / 左 Shift | 跳跃 / 静步                           |
| 1 / 2 / 3       | 主武器 / 副武器 / 匕首                |
| Q / R           | 上一把武器 / 换弹                     |
| 长按 E          | 包点安放 C4 3.2 秒 / 近距离拆除 5 秒  |
| F               | 阵亡后接管一名存活队友                |
| M / Tab         | 展开战术地图 / 按住显示本回合战绩     |

安放和拆除需要持续按住 E，移动、射击、换弹、松键或离开有效范围会中断进度。T 自动拾取附近掉落 C4。主武器、副武器和匕首都有独立第一人称模型。

## 回合

场上始终是 5 名 CT 与 5 名 T，玩家占其中一个位置，其余为本地 AI。选择手枪开局后，第一回合全部角色仅持阵营默认手枪和匕首、无主武器、无护甲；后续回合使用完整装备。全装局可选 AK-47、M4A4、AWP，以及默认手枪或沙鹰。

回合准备 3 秒，行动时间 115 秒，C4 倒计时 40 秒。T 消灭所有 CT 或引爆 C4 获胜。CT 在未下包时消灭全部 T、成功拆包或守至时间结束获胜。已下包后，消灭 T 仍需处理炸弹。结算展示 7 秒后自动开始下一回合，保留双方比分。暂停时回合、AI、炸弹计时一同暂停。

## 地图

这是保留经典核心区域与走位拓扑的程序化地图，不是原版资源或逐顶点复刻。世界约 68 × 62 米，人物约 1.9 米高，A 点和猫道抬高 1.2 米，通过 A 大坡道、CT 斜坡和猫道坡道接入，地图包括 T 出生点、CT 出生点、A 大、A 点、中门、猫道、B 洞与 B 点，以及 A 大门、A 小、B 下层洞和 CT 连接通道。中门有两扇实体打开的门体和可穿行的中央间隙。

```
                       CT 出生点
                     /     |     \
                   B 门   中门    A 斜坡
                    |      |       |
                   B 点   中路—猫道—A 点
                    |    / |        |
                   B 洞—下层洞     A 大
                    |      |        |
                    └── T 出生点 ─ A 大门
```

`map.ts` 的区域并集生成地图边界；该数据同时服务实体碰撞、遮挡射线、A* 和小地图。测试验证每个区域都能到达两个出生点和两个包点，门体和箱子保持实体碰撞。

## 实现结构

- `src/game/engine.ts`：独立全局游戏引擎，拥有角色、弹药、炸弹、回合、比分、输入和效果状态。以 60Hz 固定物理步更新，使用 `requestAnimationFrame` 渲染；暂停冻结模拟。向 React 发布约 14Hz 的纯数据快照，避免每个物理帧触发 UI 更新。
- `map.ts` / `navigation.ts`：轴分离连续小步碰撞、重力与箱顶支撑、slab 射线遮挡、静态占用网格 A*，禁止斜向穿越墙角。AI 与玩家调用同一碰撞函数。
- AI 状态：推进、交战、回收、安放、守包、拆包。按视角与墙体遮挡索敌，产生反应延迟，以实际武器射线交火；路径定期重算，受阻时重新规划。T 轮换推进 A/B，CT 在安放后赶往拆包。存活队友看到的敌人暂时同步至小地图。
- `weapons.ts`：武器配置（伤害、弹匣、射速、换弹、散布、后坐力、射程），独立枪械实例状态。头/胸/腹/臂/腿网格带有分区标记，真实射线命中；头部基础伤害为胸部的两倍，护甲吸收可用护甲范围内的伤害。
- `models.ts` / `world.ts`：几何体类人角色、持枪姿势、武器模型与沙漠建筑。静态建筑按材质实例化；第一人称武器使用独立渲染层，避免贴墙穿模。AWP 同时缩小 3D FOV 并显示圆形 2D 瞄准镜。
- `audio.ts`：噪声、滤波、振荡器、包络和立体声声像，合成枪声、换弹、脚步、开镜、命中、击杀、安放、拆除、滴答和爆炸。
- `App.tsx`：部署大厅、装备配置、暂停、准星、生命/护甲、动态弹药、实时击杀播报、小地图、战绩与结算 UI。组件卸载时清理渲染循环、输入监听、ResizeObserver、音频和 GPU 几何资源。

## 验证

```sh
npm test
```

使用 Node 内置测试器，覆盖全地图连通性、寻路不穿墙、中门通行与门体遮挡、大位移碰撞、视线遮挡、分区伤害、护甲、武器差异和包点范围。

开发模式提供 `window.__DUST2__` 引擎引用，方便在浏览器控制台检查 AI 状态、武器和回合；生产构建不发布该引用。
