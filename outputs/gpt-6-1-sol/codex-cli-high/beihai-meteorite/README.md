# 尘外 / Beyond the Dust

一部 300 秒的程序化体素电影，片头与片尾包含在总时长内。原文改编为一个封闭的故事：三块珍藏的陨石，经由一次秘密加工，被送回太空；一次例行合影，让“来自星空的礼物”变成暴力的掩饰。影片不把章北海的平静等同于道德上的正确。

## 播放

```sh
bun run dev
```

构建与查看正式产物：

```sh
bun run build
bun run preview
```

正式入口为 `dist/index.html`，保留相邻 `dist/assets/`。通过本地静态服务器或平台预览打开。无需安装依赖或访问外部资产。点击“开始放映”解锁声音；底部可暂停、跳转、调整音量与全屏。空格切换播放，左右箭头移动五秒。

## 制作文件

- `src/main.js`：唯一主播放器、完整剪辑表 `edit`、镜头运动与绝对时间表演。
- `src/worlds.js`：场景、原创皮肤与独立服装层、Voxel Kit 人物、程序化道具和地球。
- `src/voice-cues.js`：唯一配音母清单 `voiceCues`。每条严格包含 `id / kind / speaker / text / delivery / start / end`，字幕完全由清单驱动。所有待配音台词均为底部居中的 `【说话者】文本`。目前无任何人声音频。
- `src/audio.js`：独立音效清单、离线 CC0 样本与 Web Audio 主观层。地下室枪击采用冲击采样和短反射；太空射击仅表现服内传导。泄压与报警为受损航天服通讯中的主观声音。
- `src/optimize.js`：仅合并静态建筑盒子，保留全部人物骨架、衣服层和动态道具。
- `DIRECTORS_NOTES.md`：叙事取舍与完整分镜。

所有人物均由 `createFigure` 装配，未修改骨架、部件比例或分层规格。五官、眼镜、胡须、标识与面罩裂纹仅为代码绘制的纹理。道具、陨石、空间站、地球均为代码几何；没有游戏资产、外部贴图、CDN 或第三方音效素材。

音效来源：平台 Kenney CC0 离线库，所选九个采样见 `src/assets/audio/`。版权信息见 `SOUND_LICENSE.md`。
