# 陨石雨

改编自刘慈欣《三体》中章北海的一段：买陨石、造子弹、在太空里向三位航天首长开枪——一部 **352 秒、全程序生成、体素风格** 的 Three.js 短片。

- 没有任何外部素材：画面全部由代码生成（Voxel Kit 的方块人 + 体素几何），音效来自本机 CC0 音效库并内联进包里。
- 没有任何人声：所有台词、独白、广播、无线电只以字幕呈现（`【说话者】文本`），并集中在**一份**语音清单里，方便后期按 id 配音。

## 运行

```bash
bun run build      # 标准 Vite 产物：dist/index.html + dist/assets/
# 用任意静态服务器打开 dist/ 即可（相对路径 ./assets，已用 --base=./ 构建）
```

依赖只有 `three@0.180.0`、`vite@8.2.0`，以及平台提供的 `@agentbench/cinematic-player`、`@agentbench/voxel-kit`（`file:` 本地依赖）。没有运行过 `install`，没有访问网络。

**操作**：点击画面中央的播放键（或底部控制条的 ▶）· 空格 暂停/继续 · ←/→ 跳 5 秒 · F 全屏 · 拖动进度条任意跳转。首次点击才会解锁 Web Audio。载入时先画出“载入中”，第一帧渲染好后截一张海报（连同片头标题）垫在下面，同时把所有场景预热渲染一遍（有进度条）；完成后第一帧就是海报式的片头。

## 结构与导演思路（时间轴）

| 时间 | 段落 | 处理 |
|---|---|---|
| 0–26 | 序：日落前 | 冷开场。一个白色小人悬在地球弧线与将落的太阳前；瞄准镜里第一次出现黄河站，气闸紧闭。只有头盔里的呼吸与嗡鸣，两句独白（“只是存在着”“父亲的在天之灵”）。太阳触到地球边缘，切黑。 |
| 26–116 | 第一幕：四合院 | 倒叙“四个月前”。暖、旧、慢。长镜头与切入镜头（放大镜、显微镜里的火星陨石、台面）；三块铁陨石落在台面上；付款时那句“就这个价，算是我对要送的人的尊重”。 |
| 116–178 | 第二幕：制作 | 冷蓝的车间（数控机床把陨石切成 36 粒）→ 暖琥珀的地下室（拔弹头、粘陨石、试射、拆开牛肉）。**色温反差**标记了两个空间；试射的枪声送进混凝土空间的强反射，随后是耳鸣。 |
| 178–194 | 过渡：一号基地 | 他把定位单元留在舱里（桌上绿灯规律地闪）；第一次看见搁架上父亲的照片；出舱、点火、缩成一个亮点；掠过船坞里“巨兽的骨骼”。 |
| 194–346 | 第三幕：太空 | 回到日落。合影、面罩由金转透明（露出一张张脸）、摘手套/取枪/装镜、三十发子弹、十秒的等待、快门、“陨石雨！”、撤退。结尾：他闭上眼睛；切到**空无一人的舱室**——父亲的照片望着舷窗外最后一线落日，桌上的绿灯仍在闪；淡出。 |
| 346–352 | 片尾 | 黑场星空，标题与署名。 |

几个刻意的取舍：

- **不逐段还原原文**。四合院段只留“买石头”这一条线（军人、铁陨石、付款的那句话）；制作段用“对称的冷/暖”替代大段说明；开枪之前用一段瞄准镜里的**脸**（面罩逐渐透明）让观众先认识这三个人。
- **“父亲”是全片的暗线**：序里的一句话 → 过渡里第一次看见照片（钟声第二次响）→ 结尾用同一张照片收束（“不管以后发生什么，在父亲投下的目光里，我可以安心了”）。观众先看到他离开，再看到空房间和那盏绿灯——“没有人知道他离开过”。
- **揭示时机**：开枪前的 10 秒飞行时间里没有任何“子弹”镜头；只有屏息、心跳、和第一个命中时的快门闪光。

## 声音设计（“真空里没有声音”）

- 采样是主体（61 个 Kenney CC0 音效，`src/assets/audio/`，全部 `?inline` 后用 `WebAudioCueBus.defineSample` 注册）：脚步、敲门、瓷杯、保险柜、陨石落在木台上、机床门、日光灯继电器、拔弹头、枪、布、撕布、门……程序化（Web Audio）只做强化与主观声音：头盔呼吸与心跳、无线电静噪与开关键、混响脉冲、耳鸣、低音持续音。
- **地下室**：枪声（裂 + 轰 + 铮）混合后送进代码生成的混凝土脉冲响应（约 2.6 秒尾），房间底噪在枪响的一刻被“抽空”，随后是耳鸣。
- **太空**：没有任何外部枪声/推进器声。三十发子弹只有**骨传导**的闷响（手臂与头骨里的低频“咚”和更细的机械“嗒”）；别人的声音只经**无线电**（静噪、开/关键的“嚓”）；命中时被击中者的电台一闪而断。气闸泄压的嘶声越来越细，直到一片真空的静。
- 配乐克制：一个低沉的持续音，加一个反复出现的“钟”（序、照片、结尾）；开火与命中的十几秒里没有配乐。
- 时间数据共用：脚步取自人物路点与步态周期；枪声/命中/换弹取自 `schedule.ts`；弹药处理取自 `roundTimes()`。
- 声音 cue 与语音 cue 都在同一个主时间轴里；跳转/单步时不会触发被跨过的 cue（见 `engine.ts` 的门控），持续型底噪会在新位置自动接上。

## 语音清单

`src/voice/voiceCues.ts` 是**唯一**来源（`VoiceCue[]`，49 条，字段固定为 `id / kind / speaker / text / delivery / start / end`）。字幕由 `mountCinematicControls` 直接读取渲染；`bun run scripts/export-voice-cues.ts` 会导出 `voice-cues.json`。类别：`monologue`（章北海的内心独白）、`dialogue`、`broadcast`（邻家收音机）、`radio`（调度/摄影师）、`chatter`（合影者的无线电闲聊）。

## 代码结构

```
src/
  main.ts            创建 WebGL 渲染器并启动应用
  app.ts             装配：载入 UI → 影片 → ThreeStage → 声音 → 预热 → 控制条/标题 → 开始/重播
  film/              时间轴（timing）、三段式渲染（天穹→前景→屏内叠层）、镜头工具、屏内叠层（黑场/暗角/颗粒/瞄准镜）
    sequences/       opening · courtyard · making · transit · space · end：每个镜头都是绝对时间上的独立设计
  world/             courtyard · making · base · space：四个“世界”，全部是时间的纯函数
  chars/             Voxel Kit 方块人：贴图里的脸/表情/服装、姿态、道具
  sound/             samples（自动生成的内联采样表）· engine（工厂/混响/门控）· cues（音效 cue 总表）· events（脚步）
  voice/             语音清单
  ui/titles.ts       片头/片尾字幕（由播放时间驱动的 DOM 叠层）
scripts/             开发期工具（Bun）：软渲染器联系表、时间轴自检、无头“点击”模拟、声音提示单
```

- 所有角色都由 `createFigure` 创建（固定骨架与比例；脸、表情、徽章画在贴图里，衣服是独立的贴图层）；行星、空间站、船坞、地球都是体素几何（`buildVoxelGeometry` / 体素球），没有平滑球体。
- 每个镜头的 `update` 都只依赖绝对时间/局部时间，所以任意跳转与回放和正常播放一致；粒子是确定性的（按时间求值）。

## 开发脚本

```bash
bun run typecheck                                   # tsc --noEmit
bun run scripts/check-timeline.ts                   # 时间轴自检：镜头首尾相接、总时长、全片 seek 扫描（无异常/NaN）、语音清单
bun run scripts/check-determinism.ts --step 2.9 --w 128   # 确定性自检：升序/降序/乱序访问同一时刻，画面逐像素一致（约 2 分钟）
bun run --preload ./scripts/ogg-plugin.ts scripts/e2e-sim.ts   # 无头“点击”模拟（迷你 DOM + 模拟 AudioContext + 软渲染器）
bun run scripts/bundle-smoke.ts                     # 直接执行构建后的 dist 包：真实 three.js + “假 WebGL2”，把整片渲染一遍
bun run --preload ./scripts/ogg-plugin.ts scripts/cue-sheet.ts --beds   # 声音提示单
bun run scripts/shots.ts courtyard --w 560          # 软渲染器联系表（近似，非 GPU 画面）→ preview/
```

## 验证说明（如实）

本机没有任何浏览器（无 Chromium/Firefox/WebKit；`Bun.WebView` 也因找不到 Chrome 而无法启动），因此**没有做真实浏览器里的 Play 点击、暂停、跳转与控制台检查**。已经做的替代验证：

- `tsc --noEmit` 通过；`bun run build` 产出标准 `dist/`（61 个采样均已内联）。
- 用自制软渲染器逐段检查构图、色彩、曝光（近似 three r180 的光照/雾/ACES/sRGB，不含阴影与镜面）。
- `check-timeline.ts`：91 个镜头首尾相接、总长 352 s（≤ 360）、每 0.25 s 及 200 次随机跳转均无异常/NaN；语音 49 条无重叠、最快 5.8 字/秒。
- `check-determinism.ts`：每 2.9 秒取一个时刻（120 个），分别按升序、降序、随机跳转三种顺序渲染，画面逐像素一致（这项检查抓出并修掉了几处“状态遗留”：镜头之间遗留的灯光强度、手持瞄准镜的可见性、地下室碎石取用上一帧的手部位置）。
- `bundle-smoke.ts`：直接执行 `dist/assets/*.js`（构建后的生产包），用迷你 DOM、模拟 AudioContext 和一个“什么都成功、什么都不画”的假 WebGL2，让**真实的 three.js WebGLRenderer** 把整片渲染一遍（1408 帧，约 35 万次绘制调用、77 个着色器程序装配），并走一遍预热→点击播放→暂停→跳转→播到结尾：18 项检查全部通过，无异常。它能证明模块初始化与 three 的渲染路径没有 JS 异常，但**不能**证明着色器在真实 GPU 上编译、也不能证明画面。
- `e2e-sim.ts`：用迷你 DOM 走真实的 `bootstrap()`——载入期间点击、预热、点击播放、时间轴连续前进、暂停、跳转（暂停中与播放中）、键盘、整片以 0.25 s 一帧快放（463 条音效 cue 的工厂全部真正执行）、播到结尾、重播——41 项检查全部通过，无 console 错误。这**不是**浏览器，音频用的是模拟的 AudioContext（没有听过实际声音）。
