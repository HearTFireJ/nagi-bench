# 陨石雨 · 体素短片（Three.js）

改编自刘慈欣《三体》中章北海一段：一个人，为了人类将来的飞船，安静地做完了一件不能回头的事。
全片 **344 秒**（含片头片尾，上限 360 秒），完全由代码程序化生成：几何、贴图、灯光、特效与声音，没有任何外部资产。

```
bun run build      # 生成 dist/（标准 Vite 产物：dist/index.html + dist/assets/*）
bun run dev        # 本地预览
bun run typecheck  # tsc --noEmit
bun run check      # 离线校验：整条时间线、字幕清单、声音清单、确定性（见下）
```

依赖只有 `three@0.180.0`、`vite@8.2.0`，以及平台提供的 `@agentbench/cinematic-player`、`@agentbench/voxel-kit`（`file:` 本地依赖）。

## 导演思路

**取舍。** 原文的技术铺陈（太空电梯、造船业、枪弹物理）被压进三样东西：老收音机里一句“下月黄河站开会”、章北海的几句独白、以及画面里“该发生的事”。保留的是三条线的对位：

1. **收藏者的小世界**——温暖、不设防、爱石头的人；
2. **章北海的耐心**——切割、剔弹、试射，每一步都是安静的手艺活；
3. **日落**——太阳是全片的钟，沉入地球边缘的速度就是倒计时。

**结构。** 序（轨道上的等待，一句“太阳落下去的时候，他们会出来合影”）→ 片名 → 一、老宅（四个月前）→ 二、车间与地下室 → 三、日落（回到序里那一个画面，这次观众知道他在等什么）→ 尾声（同一台收音机，同一间屋子，展柜里空了一个位置）。
信息揭示的时机：石头的用途先不说（“要送的人的尊重”是双关），到地下室才亮出枪，到太空才亮出目标；合影者被写成真实、可爱的老人，杀死他们的不是恶意，而是判断——所以三个人在无线电里聊着“当年批一次发射经费要开三个月的会”，然后被击中。

**镜头语言。** 地面场景用 3/4 正反打和手持微抖；太空用长焦、对称、克制的推拉；瞄准镜是章北海的眼睛——观众用他的视线看着三位老人笑。暖冷对位：老宅里暖灯下的人 vs 展柜里冷光下的石头；太空里被日落染红的脸 vs 深蓝的地球夜面。

**声音。** 真实采样（Kenney CC0）负责脚步、开门、敲门、工具、开关、金属撞击；程序化合成负责房间底噪、收音机电流、日光灯嗡鸣、航天服风扇与呼吸、心跳、配乐；地下室枪声经一段合成的混凝土脉冲响应形成长混响。
**真空里没有空气传声：** 第 185.6 秒气闸泄压之后，画面外的一切都是无声的。三十发子弹不是“砰”，而是握枪的手感到的**三十下闷震**（`gun-thump`）；被击中的人被看见，但听不见；只有耳鸣、心跳，和航天服里的风扇。`bun run check` 会断言这一点。

## 语音清单

所有需要日后配音的内容都不合成人声，全部集中在 `src/voiceCues.ts` 的一个 `VoiceCue[]` 里（46 条，字段固定为 `id / kind / speaker / text / delivery / start / end`），字幕由播放器直接读这份清单，固定显示为画面底部居中的 `【说话者】文本`。`kind` 区分：`dialogue`（画面内对白，人物嘴会动）、`monologue`（内心独白，嘴不动）、`broadcast`（老收音机）、`radio`（无线电，只有观众能听见）、`scene`（真空里只有口型的“陨石雨！”）。

## 目录

```
src/
  main.ts            渲染器 / ThreeStage / 控制条 / 叠层 / 声音；含自适应画质
  film.ts            装配：世界、演员、道具、灯光、全部镜头、语音与音效 cue
  timeline.ts        剪辑表（镜头边界、关键事件）
  voiceCues.ts       ★ 唯一的语音清单
  overlay.ts         淡入淡出、片名、地点字幕、瞄准镜/目镜遮罩（纯函数 overlayAt(t)）
  direction/         灯光套件、镜头规格、姿态、演技辅助
  art/               方块人皮肤（五官画在贴图上）、演员、道具、粒子
  world/             太空、胡同、老宅、冰原、车间、地下室、舱室
  seq/               各段镜头设计（序、一、二、三、尾声）与人群编排
  audio/             采样注册、程序化声音、音效 cue 表
tools/               离线校验与预览（无浏览器环境下用的）
```

## 关于确定性与校验

播放器持有唯一时钟，所有画面状态（相机、姿态、粒子、灯光、显隐）都是**绝对时间的纯函数**，所以任意跳转与顺序播放得到同一画面。`bun run check` 用真实的 `CinematicPlayer`、镜头、cue 与叠层逐帧走完整条时间线：无异常；每一秒都有镜头；字幕从不重叠且可读；每个音效名都能解析；真空里没有空气传声；173 次乱序跳转与顺序播放结果逐位一致。`tools/audio-check.ts` 用一个会像真实浏览器那样抛异常的 Web Audio 模拟器把每个声音 factory 跑一遍。`tools/preview.ts` 是一个小型 CPU 光栅器，只用于创作时在没有 GPU/浏览器的环境里看构图。
